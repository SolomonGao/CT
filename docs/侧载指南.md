# CT 侧载指南（无 Mac / 免费 Apple ID）

把 CT 装到你 iPhone 上的完整流程。**无需付费开发者账号**，签名有效期 7 天（可自动续签）。

---

## 一、一次性准备（约 15 分钟）

1. **iPhone 开启开发者模式**：设置 → 隐私与安全性 → 安全性 → 开发者模式 → 打开（会要求重启）。
2. **Windows 装 iTunes（桌面版，非 Microsoft Store 版）**：Sideloadly 依赖其中的设备驱动。[下载页](https://www.apple.com/itunes/download/win64) 选"Windows（64 位，适用于 Intel/AMD 芯片的显卡支持）"旁的桌面版。
3. **装 Sideloadly**：[sideloadly.io](https://sideloadly.io) 下载 Windows 版。
4. **确认你的 Team ID**（App Groups 数据共享需要，见下）。

### Team ID 是什么 / 怎么查

免费 Apple ID 的 Team ID 是一串 10 位字母数字（如 `A1B2C3D4E5`）。查法任选其一：

- **Sideloadly 日志法（最可靠）**：先用 Sideloadly 随便装一个小 IPA，日志里会出现 `Team ID: XXXXXXXXXX`，记下来。
- 登录 [developer.apple.com/account](https://developer.apple.com/account)，部分账号在 Membership 页可见。

> 查不到也不影响安装——只是 Widget 无法与 App 共享数据（Widget 显示占位进度）。App 本体功能完整。

---

## 二、构建 IPA（GitHub 云端，约 10 分钟）

1. 打开仓库 → **Actions** → 左侧选 **Sideload** → 右侧 **Run workflow**。
2. `team_id` 填你的 Team ID（上一步查到的），留空则构建无 App Groups 版本。
3. 点 **Run workflow**，等约 10 分钟。
4. 进入这次运行，页面底部 **Artifacts** 里下载 `CT-unsigned`（解压得到 `CT-unsigned.ipa`）。

---

## 三、安装到 iPhone（约 5 分钟）

1. iPhone 连电脑，信任设备。
2. 打开 Sideloadly → 拖入 `CT-unsigned.ipa` → 输入你的 Apple ID → **Start**。
   （Apple ID 只用于向苹果换取签名证书，Sideloadly 是本地工具。）
3. 装完后 iPhone：设置 → 通用 → VPN 与设备管理 → 信任你的开发者证书。
4. 打开 **CT**：首次会要求允许数据等权限，正常给。
5. 在主屏幕添加小组件：长按桌面 → 左上角"＋" → 搜 **CT** → 选小尺寸那个。

---

## 四、日常使用注意

- **7 天重签**：免费签名 7 天到期。到期前把 iPhone 连回电脑开一次 Sideloadly 会自动续签；也可用 **SideStore**（iPhone 上自助续签，免电脑）。
- **Widget 不显示真实数据？** 说明构建时没填 Team ID。重新跑一遍 Sideload workflow 并填上 Team ID 即可。
- **换电脑/重装**：只要 Apple ID 不变，重签后数据保留（数据存在 App 自己沙盒里）。

---

## 五、进阶：付费账号（可选，$99/年）

如果你决定长期使用或给别人用：开通 Apple Developer Program 后，签名有效期变为一年，且可直接用 TestFlight 安装（无需电脑），App Groups 用 `group.<你的TeamID>.ctapp.shared` 正式注册。
